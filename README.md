# MOSS order backend

Маленький сервер на Node.js/Express, который принимает заявки из вашего
Telegram Mini App и пересылает их вам личным сообщением от бота.

## Как это работает

1. Клиент оформляет заказ в Mini App → приложение вызывает `tg.sendData(order)`.
2. Telegram доставляет это как обновление боту на адрес вебхука (`/webhook`).
3. Сервер разбирает JSON заказа, красиво форматирует и отправляет его
   вам в личный чат с ботом, а клиенту — короткое подтверждение.

## Локальная проверка (не обязательно, можно сразу деплоить)

```bash
npm install
BOT_TOKEN=ваш_токен OWNER_CHAT_ID=ваш_chat_id npm start
```

## Деплой на Render.com (бесплатно)

1. Загрузите папку `moss-order-backend` в отдельный репозиторий на GitHub
   (так же, как загружали `moss-mini-app.html` — через "Add file → Upload files").
2. На render.com: **New → Web Service** → подключите этот репозиторий.
3. Параметры сборки Render подхватит автоматически из `package.json`
   (Build Command: `npm install`, Start Command: `npm start`).
4. В разделе **Environment** добавьте переменные:
   - `BOT_TOKEN` — токен вашего бота от BotFather
   - `OWNER_CHAT_ID` — ваш личный Telegram chat_id (см. ниже, как узнать)
   - `WEBHOOK_SECRET` — любая случайная строка, например `moss-2026-secret`
5. Нажмите **Deploy**. После деплоя Render даст адрес вида
   `https://moss-order-backend.onrender.com`.

## Как узнать свой OWNER_CHAT_ID

1. Напишите своему новому боту любое сообщение (например, "привет").
2. Откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. В ответе найдите `"chat":{"id": ЧИСЛО, ...}` — это и есть ваш chat_id.

## Подключение вебхука к Telegram

После деплоя на Render выполните один раз (замените токен, адрес и секрет):

```bash
curl -X POST "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://moss-order-backend.onrender.com/webhook",
    "secret_token": "moss-2026-secret"
  }'
```

Ответ `{"ok":true,"result":true,...}` означает, что вебхук подключён.

## Проверка

Откройте Mini App через бота, оформите тестовый заказ. Вам должно прийти
сообщение от бота с деталями заказа, а клиенту (то есть вам же, в этом тесте) —
подтверждение "Заявка получена".

## Важный нюанс бесплатного тарифа Render

Бесплатный сервис на Render "засыпает" после 15 минут без запросов и
просыпается 20–30 секунд при следующем обращении — для приёма заказов
пары раз в день это не критично, но если поток вырастет, стоит перейти
на платный план ($7/мес) для мгновенного отклика.
